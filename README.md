# AdoFalling8K

为《A Dance of Fire and Ice》添加八轨下落式读谱界面的 **Unity Mod Manager（UMM）模组**。

模组根据谱面节奏生成建议指法，显示下落音符、长按尾迹、组首高亮和命中特效，支持三种排键方案及每轨颜色自定义。

当前版本：**0.8**

## 安装

当前版本使用游戏 **3.3.1 / Unity 6000** 的程序集构建，要求 **UMM 0.32.5 或更新版本**。

1. 为游戏安装 Unity Mod Manager。
2. 将 `AdoFalling8K-0.8-UMM.zip` 拖入 UMM 的 Mods 页面安装。
3. 启动游戏，在 UMM 中启用 **AdoFalling8K**。

也可以将构建生成的 `AdoFalling8K` 文件夹复制到游戏的 `Mods` 目录：

```text
A Dance of Fire and Ice/
└─ Mods/
   └─ AdoFalling8K/
      ├─ Info.json
      ├─ AdoFalling8K.dll
      └─ settings.json      # 首次加载生成
```

从旧版 **AdoFalling** 升级时，可将旧模组目录中的 `settings.json` 复制到新目录，并在 UMM 中禁用旧模组。使用过 BepInEx 版本的用户需要移走旧的 `BepInEx/plugins/AdoFalling.dll`；旧 `.cfg` 配置需重新设置。

## 快速使用

| 按键 | 功能 |
| --- | --- |
| **F5** | 打开或关闭控制面板，关闭时保存设置 |
| **F8** | 显示或隐藏下落式界面 |

启用后默认读取游戏当前谱面，无需手动选择文件。

轨道从左到右排列为：

```text
左手             右手
A  S  D  F       J  K  L  ;
         食指   食指
```

轨道表示建议指法。实际输入与判定仍由原版游戏处理，模组不会检查玩家是否按了对应轨道的键。

## 排键方案

在 **F5 → 八轨指法 → 排键方案** 中选择。

| 方案 | 分配特点 |
| --- | --- |
| **8K**（默认） | 按基础换手周期分组，优先保持左右手的交替节奏 |
| **伪4K** | 更倾向于将等间隔音符组成较长轮指，普通段优先使用中央 `D/F/J/K` |
| **4K** | 沿用伪4K，在满足外侧扩展条件的密集段中解除节奏保护下限，按原指法 BPM 重新分组 |

原「稳定轮指」更名为 **8K**，原「激进轮指」更名为 **伪4K**。此次更名保留原有排键行为和配置兼容性。

### 基本指法

单点优先使用食指，轮指按由外向内的顺序分配：

| 同手组的音符数 | 左手顺序 | 右手顺序 |
| --- | --- | --- |
| 1 | F | J |
| 2 | DF | KJ |
| 3 | SDF | LKJ |
| 4 | ASDF | ;LKJ |

普通八分连打可生成 `F J F J`，接入十六分时可生成 `F J DF KJ`。实际分组还会受到节奏保护、反拍、休止和长按占轨的影响。

三音及四音轮指要求间隔均匀：以组内第一段间隔为基准，后续间隔允许 **±5ms** 偏差。超出范围时拆分为其他组。双音轮指不受此均匀性限制。

分配器会调整反拍附近的分组边界，减少过短的换手间隔，并避开仍被长按占用的键。

### 节奏保护

**节奏保护基准(ms)** 默认约为 **166.7ms**，即 180 BPM 的八分间隔。

它限制用于分组的基础八分周期，避免高 BPM 或谱面变速将密集音符全部分配为食指单点。设为 **0** 可关闭此下限。

默认使用歌曲基础 BPM 作为指法参考，谱面的 `SetSpeed` 事件不会直接改变这个参考值。

### 伪4K 与 4K 的密集段

伪4K 以保护后的八分周期为基准：

- 相邻间隔超过该周期的 **2/3**，开始新组。
- 三音及四音组的每段间隔须不超过该周期的 **1/3**，并满足 ±5ms 均匀性。
- 未达到外侧扩展密度时，每组最多两音，优先使用中央四键。

**4K** 使用相同的外侧扩展阈值。连续三音满足扩展条件时，该密集段改用原指法 BPM 分组；离开密集段后恢复保护。孤立的快速双音、不均匀三音以及因长按占轨借用外侧键，都不会触发解除。

两种方案都保留八轨显示，密集段或长按避让时仍可能使用外侧键。

## 多押显示

默认将**相邻间隔小于 25ms** 的连续音符识别为一组多押：

- 所有成员在画面上对齐到首音。
- 使用统一的浅蓝色，默认值为 `#ADD8E6`。
- 原始时间、轨道分配、轮指分组和游戏判定保持原样。

识别会连续连接，例如 `0 / 20 / 40ms` 会组成一组；恰好 25ms 的间隔不会连接。

在 **F5 → 八轨指法 → 多押对齐窗口(ms)** 中调整，范围为 **0～100ms**，设为 **0** 关闭。统一颜色可在颜色页修改。

## 外观与对齐

控制面板支持调整：

- 判定线位置、轨道宽度、轨道间距和 **F/J 额外间距**。
- 音符下落速度、高度、透明度与各部分显隐。
- 音符提前量、长按提前量和长按长度。
- 命中特效、判定文字、自动播放与诊断信息。

**F/J 额外间距** 用于拉开左右手轨道，范围为 **0～600**。两侧各向外移动一半，组内间距保持原值。

### 音符颜色

在面板中按 **Tab** 或点击「轨道颜色」进入颜色页。

每条轨道都有独立的**普通色**和**高亮色**。每个轮指组的首音使用高亮色；单点组也使用高亮色。识别为多押时，统一使用多押颜色。

支持输入：

```text
#RRGGBB
#RRGGBBAA
R,G,B
R,G,B,A
```

RGB 数值范围为 0～255。修改后立即更新显示，关闭面板时保存。

### 面板操作

| 操作 | 功能 |
| --- | --- |
| ↑ / ↓ | 选择设置项，自动滚动到选中行 |
| ← / → | 调整数值、切换开关或排键方案 |
| Shift + ← / → | 数值调整步长放大五倍 |
| Enter | 执行按钮操作；数值行恢复该项默认值 |
| 点击数值框 | 直接输入数值，Enter 结束输入 |
| Tab | 切换参数页与颜色页 |

颜色页另支持 PageUp / PageDown 选择 RGBA 分量、Backspace 重置当前颜色、Home 重置全部轨道颜色。

## 配置与文件读谱

配置保存于：

```text
Mods/AdoFalling8K/settings.json
```

关闭面板、UMM 保存配置、禁用或卸载模组时会保存设置。手动编辑 JSON 时，请先关闭游戏。

以下高级设置位于 `Chart` 分组：

| 配置项 | 默认值 | 用途 |
| --- | --- | --- |
| `FingeringMode` | `"Stable"` | `"Stable"` 对应 8K，`"Aggressive"` 对应伪4K，`"FourKey"` 对应 4K |
| `FingeringBpm` | `0` | 0 使用歌曲基础 BPM；正数使用指定 BPM |
| `FingeringFollowSpeed` | `false` | 跟随谱面局部变速；指定 BPM 时优先使用指定值 |
| `FingeringWindowMs` | `180` | 自动换手边界保护的上限 |
| `FilePath` | 空 | 文件读谱使用的 `.adofai` 路径 |

需要文件读谱时，先设置 `Chart/FilePath`，再使用 **F5 → 文件谱面 → 载入 / 重启谱面**。文件首音会锚定到操作时刻，可通过「退出文件模式」恢复默认读取。

文件解析支持角度、速度、转向、暂停等事件，尚未完整覆盖长按及所有特殊事件。复杂谱面建议使用默认的游戏时间轴读取。

## 从源码构建

Windows 下使用系统 .NET Framework C# 编译器，无需安装 .NET SDK。构建依赖本机游戏和 UMM 程序集。

```powershell
# 构建安装包
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1

# 指定游戏目录
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 `
  -GameDir "D:\games\A Dance of Fire and Ice"

# 运行检查
powershell -NoProfile -ExecutionPolicy Bypass -File tests/run.ps1
```

产物位于 `build/`：

```text
AdoFalling8K.dll
AdoFalling8K/
AdoFalling8K-0.8-UMM.zip
```

当前版本已通过 **111 项常规检查及 2 项谱面回归检查**，覆盖排键、读谱、多押显示、颜色、配置、面板操作和 UMM 生命周期。检查使用托管宿主运行，实机渲染及与其他模组共存仍需在游戏中验证。
